# 나 얼마 벌었지?

일하는 시간만큼 월급이 도트 그림에 실시간으로 쌓이는 모바일 웹입니다.
파일은 `index.html` 하나이고, 빌드 과정이 없어요.

## 기능

- 근무형태: 평일 / 선택 / 교대 / 알바
- 교대근무는 밤 10시~아침 6시에 1.5배로 쌓임
- 근무 시간, 근무 요일, 교대 패턴(근무·휴무 일수) 직접 설정
- 급여: 월급 또는 연봉, 세후 또는 세전 (세전은 대략적인 추정치)
- 월급날을 입력하면 그날 0시에 100%가 되도록 계산 (매월 1일 0시부터 시작)
- 그림 4종: 돼지 저금통, 고양이와 상자 저금통, 별 저금통, 돈나무
- 인센티브는 시간으로 쌓이지 않고 직접 입력해서 추가
- 지금까지 경과 시간, 그동안 쌓인 금액, 살 수 있는 것 보기
- 시간대는 기기 설정을 그대로 사용

## 실행

`index.html`을 브라우저로 열면 바로 동작합니다.
글꼴(Jua, Noto Sans KR, DotGothic16)은 Google Fonts에서 불러오므로 인터넷 연결이 필요해요.

## GitHub Pages로 배포

1. 이 폴더를 저장소에 올립니다.
2. 저장소의 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 주소로 열려요.

## 데이터 저장

설정과 인센티브는 브라우저의 `localStorage`에만 저장됩니다. 입력한 금액과 설정은 서버로 보내지 않아요.
기기나 브라우저를 바꾸면 다시 입력해야 합니다.

방문 통계를 보기 위해 Firebase Analytics를 연결했어요. 방문 수와 사용 환경 같은 일반적인 통계만 수집하고, 입력한 급여나 인센티브 금액은 포함되지 않습니다.

## 참고

- 세전 → 세후 계산은 4대보험과 소득세를 단순화한 추정치입니다. 요율은 바뀔 수 있으니 정확한 금액이 필요하면 세후로 입력하세요.
- 공휴일은 반영하지 않습니다.
